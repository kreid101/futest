
## Как запустить проект

1. Создайте файл настроек:

   ```bash
   cp .env.example .env
   ```


2. Откройте `.env` и введите в `DB_PASSWORD=` свой пароль. 

3. Соберите и запустите проект:

   ```bash
   docker compose up -d --build
   ```

4. Swagger:

   https://app.swaggerhub.com/apis/kreid/futest/1.0.0#/


## Тестирование

Тестирование проводилось с заполнением базы данных через сидинг и ручной проверкой запросов в Postman.

Также есть 6 автоматических тестов: создание задачи, получение списка, просмотр одной задачи, полное обновление (PUT), частичное обновление (PATCH) и удаление. Тесты используют отдельную базу SQLite в памяти и не затрагивают данные проекта.

Запуск тестов:

```bash
docker compose exec app php artisan test
```
